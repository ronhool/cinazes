Sans Bullshit Sans Cyrillic

Встроенная тестовая страница шрифтового проекта внутри cinazes.ru. Исходники шрифта подключены из отдельного репозитория, а сама страница собрана как изолированный лабораторный модуль с общей навигацией сайта.

Live preview

Слишком много серьёзных шрифтов и слишком мало ясности.
Форматы WOFF2 / WOFF / TTF

О проекте

Исходный репозиторий живёт отдельно и подключён в cinazes как submodule. Это позволяет держать шрифтовой проект автономным, не смешивая его исходники с инфраструктурой основного сайта.

Подключение

Исходный репозиторий остаётся source-of-truth через vendor/projects/SansBullshitSans-CYR, а для статического рантайма сайт использует локальные webfont-копии. UI страницы изолирован собственными стилями и скриптом, чтобы не конфликтовать с глобальными слоями cinazes.
