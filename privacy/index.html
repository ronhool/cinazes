  • не имеет платной подписки;
  • не использует аналитику;
  • не использует рекламные трекеры.

Персональные данные пользователей сайт самостоятельно не собирает и не обрабатывает.

3. Cookie и локальное хранилище

Cinazes не использует собственные cookie и локальное хранилище браузера для аналитики, рекламы или отслеживания пользователей.

Это не относится к внешним сервисам, на которые сайт ссылается (раздел 5) — у них могут быть собственные cookie в рамках их собственных сайтов.

4. Хостинг

Сайт размещён на GitHub Pages (GitHub, Inc.).

Инфраструктура GitHub может получать технические данные запроса — включая IP-адрес и сведения об устройстве — в целях предоставления, безопасности и работы сервиса, независимо от того, что делает сам сайт cinazes.ru. Это происходит на уровне хостинга, а не по инициативе Cinazes. Подробности — в GitHub Privacy Statement.

5. Внешние ссылки

На сайте есть ссылки на внешние сервисы:

  • Telegram (канал t.me/typefeed);
  • GitHub (репозитории и страницы проектов на github.com и ronhool.github.io);
  • letterletter.org (архив-источник в разделе «Исследования»);
  • почтовый клиент пользователя — на нескольких страницах шрифтов есть mailto-ссылка для лицензионных запросов.

После перехода по такой ссылке пользователь взаимодействует уже с внешним сервисом на условиях его собственных правил обработки данных. Cinazes не отвечает за содержание и политику обработки данных сторонних сайтов.

6. Права пользователя

Поскольку сайт не собирает персональные данные напрямую (нет форм, аккаунтов, аналитики), у Cinazes на стороне сайта нет данных пользователей, которые можно было бы посмотреть, изменить или удалить по запросу.

По вопросам конфиденциальности и работы сайта можно написать на hello@cinazes.ru.

Если вы самостоятельно отправляете письмо на этот адрес, данные, которые вы укажете в письме, обрабатываются вне сайта — только в рамках переписки и ответа на обращение. Сайт не собирает эти данные через форму — mailto-ссылка лишь открывает ваш собственный почтовый клиент.
